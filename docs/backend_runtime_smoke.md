# 后端真实生成抽检

抽检素材是项目内 `夜奏花` 的 1.0–9.0 秒片段；使用的运行时为 qwen-asr 0.0.6、Transformers 4.57.6、Torch 2.14.0+cu130、RTX 4090。模型权重校验值见 [benchmark.md](benchmark.md)。这不是质量基准，目的是验证生成 ID、正文范围和时间边界的适配契约。

| 后端 / 请求 | 真实输出 | 关键证据 | 结论 |
| --- | --- | --- | --- |
| Qwen 0.6B / 自动语言 | `夜空を見上げて。` | 检测语言为 `Japanese`；共 10 个生成步；正文步为 `[3, 4, 5, 6, 7, 8]`；置信度 `0.873253` | `language Japanese<asr_text>` 语言头不在正文步或置信度中。 |
| Whisper large-v3 / `ja` | `夜空を見上げて` | 7 个时间文本单元；`夜` 为 1.000–2.020s，`空` 为 2.020–2.920s，`を` 为 2.920–5.560s | 日文 Unicode 文本从其首个 BPE token 的时间边界开始，且相邻单元连续。 |

自动化契约由 `tests/test_backend_contracts.py` 覆盖：其中的跨 token `漢` 用例固定首 token 开始边界，Qwen 语言头用例固定正文生成步。此真实抽检与完整整曲记录相互补充：前者检查适配边界，后者检查端到端行为。
